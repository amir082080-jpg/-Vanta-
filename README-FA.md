# ÀVanta LINK — نسخه گسترش‌یافته رابط کاربری

## انتشار روی GitHub Pages
1. از مخزن فعلی یک نسخه پشتیبان بگیر.
2. فایل‌های `index.html`، `manifest.webmanifest`، `icon.svg` و `sw.js` را کنار هم در ریشه مخزن قرار بده.
3. منتظر انتشار GitHub Pages بمان و سایت را با بارگذاری مجدد کامل تست کن.

## موارد مهم
- پیکربندی Firebase در `index.html` دست‌کاری نشده و فایل قوانین Firebase در این بسته وجود ندارد.
- خرید Premium کارت‌به‌کارت است؛ دکمه درخواست، ایمیل را باز می‌کند تا کاربر رسید را خودش ضمیمه کند. Premium به‌صورت خودکار فعال نمی‌شود.
- پیام‌های ذخیره‌شده، لینک ویدیوی تبلیغ و فهرست محلی درخواست‌ها در همان مرورگر ذخیره می‌شوند؛ با دستگاه‌های دیگر همگام نیستند. برای صف مشترک رسیدها و پشتیبانی بین همه کاربران، به مسیرهای دیتابیس مجاز یا سرویس backend نیاز است؛ این نسخه برای حفظ درخواست شما Firebase Rules را تغییر نمی‌دهد.
- آدرس پلنر ارائه نشده؛ لینک حدسی اضافه نشده است.
- زبان انگلیسی فعلاً فقط جهت صفحه را تغییر می‌دهد؛ ترجمه کامل هنوز پیاده نشده است.
