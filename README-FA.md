# بستهٔ ÀVanta Messenger + I VANTA

## فایل‌ها
- `index.html` — پیام‌رسان فعلی با ورودی‌های جدید I VANTA Planner و ÀVanta Premium.
- `planner.html` — نسخهٔ بازسازی‌شدهٔ برنامه‌ریز I VANTA که از فایل موجود پروژه گرفته شده.
- `manifest.webmanifest`, `icon.svg`, `sw.js` — اجزای پایهٔ نصب‌پذیری PWA.

## انتشار آزمایشی در GitHub Pages
۱. از مخزن فعلی نسخهٔ پشتیبان بگیر.
۲. فایل‌های این بسته را در ریشهٔ مخزن Pages قرار بده و `index.html` را جایگزین نسخهٔ فعلی کن.
۳. تا قبل از تنظیم Firebase Rules، تست‌ها را با احتیاط انجام بده.

## محدودیت‌های مهم این نسخه
- تنظیمات Firebase در `index.html` عمداً تغییر داده نشده‌اند.
- بخش I VANTA به‌صورت صفحهٔ جداگانه (`planner.html`) باز می‌شود؛ فعلاً ورود مشترک و همگام‌سازی پروژه‌های برنامه‌ریز با حساب پیام‌رسان پیاده‌سازی نشده، چون نسخهٔ برنامه‌ریز فعلی داده‌ها را محلی نگه می‌دارد.
- درخواست Premium فعلاً آزمایشی است و فقط در `localStorage` همین مرورگر ذخیره می‌شود؛ به پنل مدیر ارسال نمی‌شود و اشتراک فعال نمی‌کند.
- قیمت‌ها و اطلاعات پرداخت تنظیم نشده‌اند چون برای پروژهٔ جدید هنوز قیمت نهایی تعیین نشده.
- Premium واقعی، محدودیت پروژه‌ها، گپ و لینک دعوت، استوری و حذف تبلیغات نیازمند پیاده‌سازی دیتابیس/قواعد دسترسی در مرحلهٔ بعد است.
- این بسته هنوز روی GitHub Pages یا Firebase زنده آزمایش نشده است.
